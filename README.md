# Peta Hibah PPM

Aplikasi web Yayasan Eka Harap untuk menyelaraskan siklus hibah internal Penelitian dan PkM (dokumen LPPM) dengan Lampiran 6 SK Standar Biaya UNEKA.

- Data dan seluruh pilihan berasal dari Spreadsheet "Peta Hibah PPM — Data" (Apps Script terikat).
- Web diterbitkan otomatis ke GitHub Pages lewat GitHub Actions setiap ada perubahan di branch `main`.
- Satu-satunya nilai yang perlu diisi: `API_URL` di `src/config.js` (URL Web App berakhiran `/exec`).

Versi 1.0.0 — 12 Oktober 2026.
